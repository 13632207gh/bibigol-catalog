راهنمای انتشار روی GitHub Pages

1) فایل BiBiGol_GitHub_Pages.zip را دانلود و Extract کنید.
2) در مخزن bibigol-catalog روی Add file > Upload files کلیک کنید.
3) تمام فایل‌ها و پوشه‌های داخل BiBiGol_GitHub_Pages را انتخاب و در صفحه GitHub رها کنید.
   دقت کنید index.html باید مستقیماً در ریشه مخزن قرار بگیرد.
4) پایین صفحه روی Commit changes کلیک کنید.
5) وارد Settings > Pages شوید.
6) در بخش Build and deployment:
   Source = Deploy from a branch
   Branch = main
   Folder = /(root)
7) روی Save کلیک کنید.
8) چند دقیقه بعد آدرس سایت نمایش داده می‌شود.

فایل‌های اصلی:
index.html
styles.css
app.js
catalog.pdf
assets/
.nojekyll
